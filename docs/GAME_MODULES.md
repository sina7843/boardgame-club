# Original engine proof games

These two original deterministic demo rules are execution fixtures, not a promised commercial launch catalog. Both support friendly/ranked (after phase 03), live/turn-based and one resumable interactive Persian tutorial. No AI players.

## line-three — public state, alternating turns
Exactly 2 players, 3×3 board, X/O. First actor chosen by engine seeded RNG at setup and persisted. Players alternate placing their symbol on an empty cell. Three matching symbols in row/column/diagonal wins; full board without winner draws. Illegal cell, wrong actor, duplicate cell and actions after finish reject. Engine onTimeout makes current actor lose; resignation makes resigning actor lose. Public projection includes board, actor and outcome but never RNG state. One versioned module and accessible DOM/SVG renderer; literal coordinates stay identical in RTL shell.

## sealed-bids — hidden information, simultaneous decisions
2–4 players. Each player privately receives tokens 1–5; five rounds, public round prizes 1/2/3/4/5 in order. Each round all players secretly commit exactly one unused token; cannot alter commitment. Hidden token availability of opponents and pending bid values never enter another player's or spectator's view/legal-action hints. A player sees own remaining tokens and own committed bid; public sees only who has submitted.
Once all seats submitted, reveal bids atomically. Unique highest bid wins that round's prize points; tie for highest gives no points. All submitted tokens are consumed. Progress to next round; after round 5 largest score wins, equal scores share placement. Final public recap can show only already-revealed bids.
If deadline fires before all submitted, engine commits the lowest unused token for missing actors in stable seat order, then resolves. Resignation uses the same deterministic lowest-token policy for that seat for remaining rounds, no bot service. Document this policy before start. Setup shuffles seat order with persisted seeded RNG; rules use only logical time and RNG from EngineContext. Renderer includes private hand, public score/round, sealed-submit feedback and accessible reveal; never exposes another player's bid before reveal.
