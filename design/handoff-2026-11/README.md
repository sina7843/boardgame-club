# بردگیم‌ورس: تحویل کامل طراحی (آبان ۱۴۰۵)

این زیپ همهٔ طراحی تأییدشدهٔ بردگیم‌ورس را یکجا دارد: دیزاین سیستم v2.4.3 با فونت‌ها و کامپوننت‌ها، همهٔ صفحه‌های سایت، و میز هر ۶۸ بازی با قانون‌هایشان. هر ۱۱ بستهٔ تحویل قبلی بدون تغییر در یک ساختار ادغام شده‌اند و هیچ فایلی روی فایل دیگری ننشسته است (`docs/MERGE-LOG.md`). همه‌چیز برای اجرا با **Claude Code** آماده است.

## شروع
1. محتوای `repo/` را در ریشهٔ ریپوی `boardgame-club` کپی کنید. این کار ادغام است و چیزی پاک نمی‌شود. `CLAUDE.md` همین زیپ را هم کنار ریپو بگذارید، یا محتوایش را به `CLAUDE.md` ریپو اضافه کنید.
2. یک بار `node design/install.mjs` را اجرا کنید.
3. در Claude Code دستور `/bgv-start` را بزنید. وضعیت ریپو را چک می‌کند و می‌گوید مرحلهٔ بعد کدام است.
4. هر مرحله را روی یک شاخهٔ جدا انجام دهید و با PR ادغام کنید. **هر push روی `main` ممکن است سایت زنده را به‌روز کند.**

## ترتیب مرحله‌ها
دیزاین سیستم (`/bgv-implement`) ← شطرنج ← گروه الف ← گروه ج ← گروه ب ← گروه د ← گایا ← ترافورمینگ مارس ← برس ← آرک نوا ← بلاد ریج.

هر بسته سه دستور دارد: `implement` برای ساخت، `qa` برای بررسی و `fix` برای اصلاح تا وقتی QA قبول شود. شرح هر بسته در `packages/<نام>/START-HERE.md` است.

## کجا چیست
| مسیر | محتوا |
|---|---|
| `CLAUDE.md` | دستورالعمل اصلی Claude Code: ساختار، ترتیب کار، قانون‌های قطعی طراحی، وضعیت و خطرهای ریپو |
| `repo/design/` | دیزاین سیستم: توکن‌ها، کامپوننت‌ها، فونت‌ها (پیدا با ۹ وزن، Manrope و Vazirmatn با مجوزشان)، برند و favicon، صفحه‌های مرجع |
| `repo/design/games/` | میز بازی‌ها: HANDOFF، COMPONENTS، QA-CHECKLIST، تصویر قطعه‌ها و `RULES.md` هر بازی |
| `repo/.claude/` | دستورها، ایجنت‌های QA و مهارت دیزاین سیستم برای Claude Code |
| `docs/START-HERE.md` | ترتیب نصب و توضیح هر بسته |
| `docs/QA-REPORT.md` | گزارش کامل QA در همهٔ دورها |
| `docs/RULES-INDEX.md` | فهرست ۶۸ فایل قانون |
| `docs/PENDING.md` | موارد باز |

## قانون‌های قطعی (خلاصه؛ متن کامل در `CLAUDE.md`)
- فقط از توکن‌ها و کامپوننت‌های دیزاین سیستم استفاده شود.
- سایه‌ها سفت و «چاپی» بمانند.
- جداکنندهٔ هزارگان کامای معمولی است: «۲,۴۸۰».
- بازه‌ها به شکل «X تا Y» نوشته شوند.
- رقم فارسی بدون `tabular-nums`.
- عکس جعبهٔ بازی با کلاس مشترک و `drop-shadow`.
- در چت، پیام خودم راست و پیام بقیه چپ.
- نام بازی‌ها طبق `GAME_NAMES.md`.
- منبع قانون: اول BGA، بعد دفترچهٔ رسمی.
- هیچ قطعهٔ بازی از خود ساخته نشود.
