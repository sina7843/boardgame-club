# Blood Rage: بستهٔ تحویل به تیم فنی (v1.0، ۲۰۲۶-۱۰-۳۰)

صفحهٔ بازی بلاد ریج (اسلاگ `blood-rage`) به سبک BoardGameArena. چیدمان از روی میز Blood Rage خود BGA اندازه گرفته شده: یک بازی ضبط‌شدهٔ عمومی و یک میز زنده در ۱۴۴۰ پیکسل. رنگ‌ها و کامپوننت‌های سایت از دیزاین سیستم است. هنر: مجموعهٔ BGA در `Games Redesign/blood-rage/ready to use` (بازی پایه + بازیکن پنجم). مجوز CMON برای بلاد ریج گرفته شده (تأیید کاربر ۲۰۲۶-۱۰-۳۰).

**فرق اصلی با گایا، ترافورمینگ و برس: ریپو موتور بلاد ریج ندارد.** تیم فنی موتور را هم می‌سازد؛ قرارداد کامل در `ENGINE.md`.

## تصمیم‌های اصلی (قطعی، تأیید کاربر ۲۰۲۶-۱۰-۳۰)

| موضوع | تصمیم |
| --- | --- |
| مجوز | CMON مجوز داده؛ هنر BGA همان‌طور که هست |
| نسخه | بازی پایه + بازیکن پنجم (۲ تا ۵ نفر)؛ هیچ توسعهٔ دیگر |
| زبان کارت‌ها | کارت‌ها همان تصویر انگلیسی BGA؛ نام و متن فارسی فقط در راهنمای کارت (hover / نگه‌داشتن) و `aria-label`. زیر کارت‌ها نوشته‌ای نیست (BGA) |
| چیدمان دسکتاپ (BGA) | ستون بازی: نوار وضعیت چسبان ← جعبهٔ نقشه ← (در درفت: «یک کارت نگه دارید») ← «دست من» ← صفحه‌های قبیله (شما اول، بعد به ترتیب نوبت). ستون راست ۳۰۰ پیکسل: پنل بازیکن‌ها، بعد گزارش |
| نوار وضعیت | دکمه‌های BGA با همان برچسب: «یک اقدام انتخاب کنید» (بازی مأموریت/ارتقا/هیولا فقط با چنین کارتی، یورش، لشکرکشی، غارت، کنار کشیدن) ← «یورش با: …» (یک دکمه برای هر نوع مهرهٔ ذخیره با هزینه) ← «روستا را برای یورش با … انتخاب کنید» ← «ثبت / انصراف». هدف‌ها فقط روی نقشه و صفحهٔ قبیله |
| ثبت | فرق ما با BGA: پیش از ارسال «ثبت» داریم (قانون DS). «انصراف» فقط پیش از ثبت؛ پس از ثبت برگشت نیست؛ پنجرهٔ «انصراف» پس از ارسال برای این بازی خاموش. یک خط زیر نوار هزینه و اثر را می‌گوید (مثلاً «اثر ترول: جنگجوی آرش نابود می‌شود») |
| جعبهٔ نقشه | ۷۲۰ پیکسل ارتفاع (BGA: ۸۰٪ ارتفاع صفحه)؛ نقشه در ارتفاع جا می‌شود و روی دریا می‌نشیند. لوگو بالا چپ؛ نشان «عصر n» و فلش‌های بخش قبلی/بعدی بالا راست؛ «آخرین نبرد» بالا وسط؛ بزرگ‌نمایی چپ؛ بایگانی نبردها، کارت‌های دورریخته و «والهالا (n)» پایین چپ |
| روی نقشه | نشان غارت وسط هر استان؛ استان غارت‌شده: پلاک تیرهٔ «غارت موفق توسط …» (BGA)؛ استان نابود: قرص راگناروک؛ نشان نابودی روی جای doom استانِ این عصر؛ مهره‌ها توکن‌های BGA (ارتقایافته = توکن کارت) به اندازهٔ ۱۱٪ عرض نقشه |
| صفحهٔ قبیله | ۹ جایگاه به ترتیب BGA: ۵ ستون [قبیله، سردار، جنگجو، هیولا، هیولا] / [—، کشتی، قبیله×۳]؛ ≥۱۷۲۰ پیکسل ۹ در یک ردیف؛ ≤۱۱۰۰ سه ستون. **همیشه چپ‌به‌راست**، در فارسی هم (قانون کاربر از گایا). بالایش نام و دکمه‌های «ذخیره: n» و «مأموریت‌ها: n» (پنجره) |
| پنل بازیکن (BGA) | نام + لیگ، «n ★ افتخار»، نشان قبیله، جعبهٔ خشم (عدد سفید روی آرت خشم)، کارت دست، شاخ بازیکن اول، سه ویژگی «مقدار/حداکثر»، «جزئیات آمار». بدون داشبورد بالای ستون |
| رنگ | رنگ قبیله‌های BGA (`layout.json → clanColors`)، فقط داخل `.bdr` |
| ریسپانسیو | ≤۱۱۰۰: پنل‌ها یک ردیف افقی بالای نوار، فازها یک‌ستونی؛ ≤۷۶۰: نقشه مربع، بزرگ‌نمایی پنهان. گوشی واقعی: شش صفحهٔ §۲۵ تا §۳۰ |
| فازها | همه: درفت، اقدام (همهٔ اقدام‌ها و تصمیم‌ها)، نبرد، دور ریختن، مأموریت، راگناروک، آزادی والهالا، پایان بازی |

## هنر

همهٔ قطعه‌ها از `art/`؛ نقشه = `boards/main-board.webp` روی `backgrounds/sea-background.webp`. هیچ قطعه، کارت یا نشانی با CSS/SVG/HTML کشیده نشود. نگاشت: `data/content-id-map.json`. قطعه‌ای کم نیست؛ مسیر عصرها، والهالا و مسیر افتخار فیزیکی در BGA هم پنل رابط‌اند و اینجا هم پنجره/عدد هستند (تصویر جدا ندارند). کارت‌ها ۱۵۰×۲۳۰ پیکسل‌اند (اندازهٔ اصلی BGA): بزرگ‌تر از ۱۵۰ نمایش داده نشوند؛ در راهنما هم ۱۵۰.
