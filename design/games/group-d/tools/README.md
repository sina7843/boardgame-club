# ابزار ساخت آرت‌بوردها

`gd.mjs` قاب مشترک است و هر بازی یک ماژول در `cards-d/<slug>.mjs` دارد. این‌ها فقط برای بازسازی آرت‌بوردهای طراحی‌اند، نه کد سایت.
ساخت: `node --experimental-strip-types gd.mjs <slug,...>` (مسیرهای مطلق داخل فایل‌ها مال ماشین طراح است). قاب گروه الف از ابزار شطرنج (`bgv-chess/tools`) استفاده می‌کند.
