# ابزار ساخت آرت‌بوردها

`ga.mjs` قاب مشترک است و هر بازی یک ماژول در `games/<slug>.mjs` دارد. این‌ها فقط برای بازسازی آرت‌بوردهای طراحی‌اند، نه کد سایت.
ساخت: `node --experimental-strip-types ga.mjs <slug,...>` (مسیرهای مطلق داخل فایل‌ها مال ماشین طراح است). قاب گروه الف از ابزار شطرنج (`bgv-chess/tools`) استفاده می‌کند.
