# کامپوننت‌های گروه الف: بازی‌های صفحه‌ای دونفره

## قاب مشترک
| # | جزء | کلاس آرت‌بورد | نکته |
| --- | --- | --- | --- |
| ۱ | نوار بازی | `bgv-gamebar` | نام فارسی + لاتین، حالت (زنده/نوبتی)، تعداد نفر، زمان نوبت، صدا، چت، منو |
| ۲ | ریل | `cx-rail` (`aside`) | ۳۸۰px در دسکتاپ؛ وضعیت، کارت راهنما، رویدادها، دکمه‌ها |
| ۳ | وضعیت | `cx-status` | جملهٔ نوبت با نقطهٔ نوبت؛ کوتاه و فعل‌دار |
| ۴ | کارت راهنمای بازی | `cx-card` + `ga-rule` / `gc-pills` | یک کارت؛ قانون کلیدی همین لحظه |
| ۵ | رویدادها | `cx-log` | آخرین رویداد پایین؛ رنگ صندلی |
| ۶ | ردیف دکمه‌ها | `cx-actions` | دکمه‌های DS؛ «ترک میز» با variant `leave`؛ قوانین و تنظیمات آیکونی |
| ۷ | میز ماهوتی | `cx-felt` | زمینهٔ `--felt`؛ رندرر بازی داخلش |
| ۸ | نوار بازیکن | `cx-pbar` | آواتار با حلقهٔ صندلی، نام، رتبه، ساعت (`cx-clock`) |
| ۹ | گفت‌وگو | `bgv-chat` | DS v2.4.1: شما راست، دیگران چپ |
| ۱۰ | گوشی: داک | `cx-pdock` | چهار کار پرکاربرد همان بازی |
| ۱۱ | صفحهٔ بازی | `ga-board` | ۵۷۲px دسکتاپ، ۳۶۶px گوشی؛ هدف‌ها: نقطه = خالی، حلقه = زدن |
| ۱۲ | فهرست حرکت | `cx-ml` / گوشی `cx-ms` | نمادگذاری خود بازی؛ نوار گوشی افقی و آخرین حرکت راست |

کلاس‌های `cx-*` و `ga-*`/`gc-*` نام‌های آرت‌بوردند، نه کلاس DS؛ در کد از کامپوننت‌های DS (`TableScreen`، `PlayerCard`، `Clock`، `MoveLog`، `ActionDock`، `Chat`) استفاده کنید.
