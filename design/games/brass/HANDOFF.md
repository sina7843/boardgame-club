# Brass: Birmingham: بستهٔ تحویل به تیم فنی (v1.0، ۲۰۲۶-۱۰-۲۹)

صفحهٔ بازی برس: بیرمنگام (اسلاگ `brass`) به سبک BoardGameArena. چیدمان از **Brass: Lancashire** در BGA گرفته شده، چون Brass: Birmingham در BGA نیست؛ همهٔ قانون‌ها، هنر و صفحه مال **بیرمنگام** است (موتور `games/brass/src`، هنر `Games Redesign/brass-birmingham/ready to use - flat`). هیچ قطعه‌ای از لنکاشایر استفاده نشده.

| | |
| --- | --- |
| اسلاگ و کد | `brass` → `games/brass/src/` (`rules.ts`، `content/`، `renderer.tsx`، `renderer.css`) |
| دیزاین | کانواس صفحه‌ها، صفحهٔ «۱۴. پایلوت BGA: برس» (۱۱ آرت‌بورد زیر `brass/`) |
| پیش‌نیاز | بستهٔ دیزاین سیستم v2.1 (ریپو امروز v1.3 دارد). بسته‌های گایا و ترافورمینگ پیش‌نیاز نیستند |
| کلاس و توکن | همه زیر `.br`؛ کلاس‌ها `br-*`، توکن‌ها `--br-*`، در `games/brass/src/renderer.css` |
| دادهٔ مرجع | `data/mock-state.json`: یک بازی واقعی ۴ نفره با همین `rules.ts` (بذر ۳۳)؛ همهٔ عددهای آرت‌بوردها از آن است |

| فازها | نوبت عادی و هر هفت اقدام، دور اول کانال، پایان دوره (درآمد، امتیاز، حذف سطح I)، پایان بازی، آموزش |

### هزینهٔ اقدام‌ها (کار کوچک در لایهٔ بازی)

کلاینت دست حریف‌ها و ترتیب دسته را ندارد، پس هزینهٔ دقیق را سرور می‌دهد. در `legalFor` هر hint یک فیلد `cost` بگیرد که از همان اجرای آزمایشی `check()` (کپی وضعیت + `perform`) ساخته می‌شود؛ شکلش در `data/mock-state.json` → `main.hints[].cost` است: `money`، `spent`، `coalMarket`، `ironMarket`، `from[]` (منبع زغال/آهن/آبجو با صاحب و تعداد)، `beerMerchant[]`، `income`، `incomeLevel`، `vp`، `flipped[]`، `built`. این تغییر فقط در `games/brass/src/rules.ts` است، قانونی را عوض نمی‌کند و تست‌های موتور باید سبز بمانند. برای ریل دوتایی هم همان.
