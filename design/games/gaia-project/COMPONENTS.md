# Gaia Project: فهرست کامل کامپوننت‌ها

هر کامپوننتی که روی صفحهٔ بازی گایا دیده یا زده می‌شود، با هر چیزی که برای ساختنش لازم است. Claude Code از این فایل کار می‌کند و QA (`QA-CHECKLIST.md`) هر بند را با همین شماره‌ها چک می‌کند.

**قرارداد مختصات (برای همه):** عددهای `layout.json` مرکز قطعه روی تصویر منبع‌اند (پیکسل). قطعه را با `position:absolute; left: x/W·100%; top: y/H·100%; transform: translate(-50%,-50%)` و عرض درصدی از عرض صفحه بگذارید. صفحه‌ها `position:relative; inline-size:100%` با تصویر پایه `position:static; inline-size:100%; block-size:auto`. همه چیز درصدی است، پس در هر عرضی (۱۴۴۰ تا ۳۹۰) درست می‌نشیند.

**پیاده‌سازی مرجع CSS:** بلوک `<style>` هر فایل `reference/html/gaia/*.html` همان CSS آرت‌بورد است. کلاس‌های `gp-*` را از آنجا به `games/gaia-project/src/renderer.css` بیاورید. رنگ و فاصله از توکن‌های DS (`var(--…)`)؛ رنگ‌های سخت‌کد فقط همین‌هایی که در جدول توکن‌ها آمده.

## ۰. توکن‌های بازی (`--gp-*`، فقط در `renderer.css`)

| توکن | مقدار | کاربرد |
| --- | --- | --- |
| `--pick` | `#E8A642` | حلقهٔ قابل انتخاب/انتخاب‌شده روی ماهوت (کیت ۱) |
| `--hexline` | `rgba(132,164,214,.85)` | استروک دور هر بخش نقشه |
| `--own` | رنگ جناح بیننده (جدول پایین) | استروک دوم ساختمان‌های خودی |
| استروک تیره | `#0D1A23` | ۴ `drop-shadow` ۱٫۵px دور هر قطعه |
| کاسهٔ قدرت | `#6F2A82` (I/II/III)، `#2E7D4F` (G) | دایره‌های پنل بازیکن |

| رنگ | `--own` |

| yellow | `#F5D04A` |

## ۱۲. دسترس‌پذیری و زبان

- هر قطعهٔ قابل زدن `button` با `aria-label` فارسی (مثل «اقدام قدرت: ۴ قدرت: ۲ سنگ معدن، استفاده شده»)؛ تصویر تزئینی `alt=""`.
- ارقام فارسی در لایهٔ فارسی، بدون `tabular-nums` و `letter-spacing`؛ هزینه‌ها و `+۹` با `unicode-bidi:isolate; direction:ltr`.
- صفحه‌ها همیشه `dir="ltr"` (هنر چپ‌به‌راست است)؛ متن‌ها `dir` زبان.
- EN: فقط لایهٔ بازی (نوار کنش، توضیح‌ها، گزارش، برچسب‌ها)؛ پوسته و چت فارسی می‌مانند. ریل همیشه سمت راست.
- تیره: فقط توکن‌های DS عوض می‌شوند؛ هنر بازی همان.
