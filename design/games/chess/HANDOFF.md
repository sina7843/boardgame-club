# شطرنج: بستهٔ تحویل به تیم فنی (v1.0، ۲۰۲۶-۱۱-۰۸)

میز شطرنج بردگیم‌ورس (اسلاگ `chess`) در سطح Chess.com، برای مسابقهٔ شطرنج هفتهٔ بعد. مالک طراحی را در ۱۸ آبان ۱۴۰۵ تأیید کرد («شطرنج تاییده»).

**فرق با بسته‌های دیگر:** موتور شطرنج در ریپو هست و درست کار می‌کند (۶۳ تست فیده: ۵۷ قبول، ۰ رد). این بسته میز را از نو طراحی می‌کند و چند تغییر کوچک موتور و پلتفرم را می‌خواهد (`ENGINE.md`).

| | |
| --- | --- |
| اسلاگ و کد | `chess` → `games/chess/src/` (همین حالا: `rules.ts`، `definition.ts`، `renderer.tsx`، `renderer.css`، `pieces.tsx`، `pgn.ts`، `bot.ts`) |
| دیزاین | کانواس «بردگیم‌ورس — میز بازی‌ها»، صفحهٔ «۱. شطرنج، میز مسابقه»: ۱۴ دسکتاپ، ۱۹ گوشی، ۱ مشخصات (`reference/screens.json`) |
| پیش‌نیاز | دیزاین سیستم v2.4 (فونت پیدا) و قانون چت v2.4.1 (پیام خودتان راست، دیگران چپ). بستهٔ بازی‌های دیگر لازم نیست |
| کلاس | ریشهٔ فعلی `.ch` و پیشوند `ch-*` بماند. نام‌های `cx-*` در طرح فقط برچسب طراحی‌اند؛ نگاشت در `COMPONENTS.md` |
| دادهٔ مرجع | `data/scenes.json`: همهٔ وضعیت‌های آرت‌بوردها با FEN، SAN و حرکت‌های مجاز، ساخته‌شده با موتور همین ریپو |

## تصمیم‌های مالک (قطعی)

| موضوع | تصمیم |
| --- | --- |
| زمان‌ها | ردیف اصلی ۱، ۳، ۵ و ۱۰ دقیقه بدون اضافه‌زمان. «زمان‌های بیشتر»: ۱+۱، ۳+۲، ۵+۳، ۱۰+۵، فقط برای بازی با دوست و مسابقه |
| انتخابگر زمان | سه ردیف با اسم دسته یک بار در ابتدای ردیف: «بولت»، «بلیتس»، «رپید» (نه روی هر کاشی) |
| نوع رقابت | همان کنترل فعلی سایت: «نوع رقابت: دوستانه / رتبه‌دار» (`QuickMatch.tsx`). بازهٔ امتیاز نمایش داده نمی‌شود |
| صفحه و مهره | پیش‌فرض صفحهٔ «سبز مسابقه‌ای» با مهره‌های «کلاسیک تخت». شش مجموعه و هفت تم دیگر در تنظیمات |
| تمام شدن وقت | اگر حریف فقط شاه، شاه و فیل، یا شاه و اسب داشته باشد، مساوی است (قاعدهٔ Chess.com، همان رفتار فعلی موتور) |
| پیشنهاد مساوی | در هر نوبتی، مثل Chess.com (تغییر موتور D7 در `ENGINE.md`) |
| واژه‌ها | زبان شطرنج‌بازهای ایرانی: بولت، بلیتس، رپید، پری‌موو، آنالیز، مساوی، تماشاچی، سوئیس. جاهایی که سایت واژه دارد، همان: «رتبه»، «دوستانه / رتبه‌دار» |
| چیزی که نباید باشد | کارت تبلیغ یا ثبت‌نام مسابقه در لابی؛ عدد یا آمار ساختگی |
| قانون چت | پیام خودتان راست، پیام دیگران چپ، دکمهٔ ارسال راست (DS v2.4.1) |

## چیدمان

- **دسکتاپ (قاب میز دیزاین سیستم):**
  - ستون راست ۳۸۰ پیکسل: وضعیت، کارت پیشنهاد مساوی، حرکت‌ها، دکمه‌های میز.
  - وسط: نمد با صفحهٔ ۶۸۸ پیکسلی و دو نوار بازیکن.
  - چپ ۳۴۰ پیکسل: گفت‌وگو.
  - زیر ۱۲۰۰ پیکسل گفت‌وگو به دکمهٔ نوار بالا می‌رود.
- **گوشی:**
  - صفحه تمام عرض (۳۹۰)؛ حریف بالا، شما پایین، ساعت کنار اسم.
  - زیر صفحه نوار وضعیت و نوار افقی حرکت‌ها.
  - داک پایین: گزینه‌ها، مساوی، تسلیم، قبلی، بعدی.
- **صفحه:**
  - همیشه `dir="ltr"`؛ مختصات داخل خانه‌ها.
  - شما پایین (اگر سیاه هستید، صفحه برعکس).
  - تماشاچی از دید سفید می‌بیند و می‌تواند صفحه را بچرخاند.

## صفحه‌های طراحی‌شده

| آرت‌بورد | چیست |
| --- | --- |
| `D01-lobby` / `P01`، `P02` | بازی جدید: آنلاین / با دوست / با ربات، زمان‌ها، نوع رقابت، «بازی کن»، جست‌وجوی حریف با شمارنده و «لغو» |
| `D02-turn` / `P03` | نوبت شما: انتخاب مهره، نقطهٔ حرکت مجاز، حلقهٔ زدن، حرکت آخر، مهره‌های گرفته‌شده و اختلاف مادی |
| `D03-check` / `P04` | کیش: هالهٔ قرمز شاه، فقط حرکت‌های رفع کیش |
| `D04-promotion` / `P05` | ارتقا: ستون وزیر، اسب، رخ، فیل و ✕ |
| `D05-premove` / `P06` | پری‌موو در نوبت حریف (شما سیاه، صفحه برعکس)، ساعت هشدار |
| `D06-lowtime` / `P07` | وقت کم: ساعت قرمز با دهم ثانیه |
| `D07-draw-offer` / `P08` | پیشنهاد مساوی از حریف: قبول، رد، حرکت = رد |
| `D08-resign` / `P09` | تأیید تسلیم؛ حالت «پیشنهاد مساوی فرستاده شد» |
| `D09-game-over` / `P10`، `P11`، `P18` | پایان بازی: برد با مات، مساوی با تکرار، باخت با وقت؛ جدول همهٔ دلیل‌های پایان |
| `D10-reconnect` / `P13` | قطع شدن اتصال شما: ساعت می‌رود، دکمه‌ها غیرفعال |
| `D11-opp-offline` / `P14` | قطع شدن حریف: ساعت خط‌چین، همچنان کم می‌شود |
| `D12-spectator` / `P15` | تماشاچی و مسابقه: دور، میز، جدول خلاصه، گفت‌وگوی جدای تماشاچی‌ها |
| `P16` | بین دو دور مسابقه: امتیاز، حریف دور بعد، شمارش معکوس، «آماده‌ام» |
| `P12` | همهٔ حرکت‌ها (شیت از «گزینه‌ها») |
| `D13-dark` / `P17` | حالت تیره |
| `D14-en-passant` / `P19` | آن‌پاسان: تنها حرکت سرباز e5، حلقه روی سربازی که زده می‌شود |
| `Chess-Spec` | مشخصات: زمان‌ها، مدل ساعت، هشدارها، حالت‌های ساعت، پری‌موو، لابی، مسابقه، تغییرهای لازم، ظاهر، کامپوننت‌ها |

## آنچه طراحی نشده (از الگوی موجود بسازید و برای بازبینی علامت بزنید)

- فلش کشیدن با کلیک راست (رنگ در `layout.json` هست).
- صفحهٔ آنالیز بعد از بازی (فقط دکمه‌اش هست).
- پنجرهٔ تنظیمات کامل (محتوا در مشخصات §۹).
- «بازی دوباره» وقتی حریف رد می‌کند.
- اعلان‌های صوتی (فقط قاعده‌اش در مشخصات آمده).
