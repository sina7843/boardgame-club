# qa-pages.mjs (دسترس‌پذیری و قواعد DS، از بستهٔ v2.1.6)

مکمل `/bgv-qa`: بررسی axe-core (WCAG 2.0 A/AA، 2.1 AA، 2.2 AA) روی صفحه‌های واقعی.

`qa-pages.mjs` هر صفحه را در چند عرض باز می‌کند و دو دسته بررسی انجام می‌دهد:

- **axe-core:** با برچسب‌های WCAG 2.0 A/AA، 2.1 AA و 2.2 AA.
- **قواعد دیزاین سیستم:**
    - خطای JS و اسکرول افقی؛
    - سایه‌ی نرم (blur)، جز سایه‌ی تماس عکس جعبه؛
    - کهربایی پر روی چیزی جز اقدام اصلی، «بازی سریع» هدر، آیتم فعال داک، سکه و نوبت؛
    - بیش از یک اقدام اصلی کهربایی در صفحه؛
    - ناحیه‌ی لمس کمتر از ۲۴px روی گوشی؛
    - رقم لاتین یا «·» کنار عدد در متن فارسی؛
    - اسم‌های قدیمی («حریف‌یابی»، «اشتراک ویژه» و…)؛
    - بیش از یک آیتم فعال در داک.

## نصب

```bash
npm i -D playwright axe-core
npx playwright install chromium
```

## اجرا

```bash
node scripts/qa-pages.mjs http://localhost:3000/ http://localhost:3000/games --widths=390,1000,1440
node scripts/qa-pages.mjs http://localhost:3000/settings --dark --out=qa-settings.json
```

- خروجی برای هر صفحه و عرض ✓ یا ✗ است، با فهرست مشکل‌ها.
- اگر صفحه‌ای مشکل داشته باشد، کد خروج ۱ است و می‌شود آن را در CI گذاشت.

## موارد شناخته‌شده

- **کنتراست زیر پرده‌ها:** axe متنِ پشت پرده‌ی تیره‌ی مودال را هم می‌سنجد. اگر عنصر واقعاً زیر مودال و غیرفعال است، کاذب است.
- **رقم لاتین مجاز:** نام لاتین بازی‌ها و نمادهای قراردادی (مثل شطرنج) را داخل `.bgv-latin` یا `dir="ltr"` بگذارید تا شمرده نشوند.
- **قرص نوبت:** با `.bgv-turn--mine` یا `.bgv-badge--turn` بسازید. کلاس‌های محلی (مثل `cx-f-turnpill` در ماکت خانه) «کهربایی روی غیر اقدام» گزارش می‌شوند.
