# پیدا (Peyda)

فونت فارسی بردگیم‌ورس از v2.4. نسخه ۲٫۰۰۰ (PeydaWeb)، ساخت فونت‌ایران.

| وزن | فایل |
|---|---|
| 100 | `Peyda-Thin.woff2`، `Peyda-Thin.woff` |
| 200 | `Peyda-ExtraLight.woff2`، `Peyda-ExtraLight.woff` |
| 300 | `Peyda-Light.woff2`، `Peyda-Light.woff` |
| 400 | `Peyda-Regular.woff2`، `Peyda-Regular.woff` |
| 500 | `Peyda-Medium.woff2`، `Peyda-Medium.woff` |
| 600 | `Peyda-SemiBold.woff2`، `Peyda-SemiBold.woff` |
| 700 | `Peyda-Bold.woff2`، `Peyda-Bold.woff` |
| 800 | `Peyda-ExtraBold.woff2`، `Peyda-ExtraBold.woff` |
| 900 | `Peyda-Black.woff2`، `Peyda-Black.woff` |

- **مجوز:** تجاری، با مالک. فایل‌ها فقط برای boardgameverse.ir هستند.
- **ارقام:** ارقام لاتین شکل لاتین دارند. رقم فارسی (U+06F0 تا U+06F9) را خود متن بنویسد. `tabular-nums` به کار نرود.
- **بارگذاری:** `font-display: swap`. برای صفحه‌های عمومی وزن ۴۰۰ و ۷۰۰ را `preload` کنید.
- **فایل CSS:** `peyda.css` همه ۹ وزن را با `@font-face` تعریف می‌کند؛ کنار فایل‌های فونت بگذارید یا مسیرها را عوض کنید.
- **نیازمندی:** مرورگرهای امروزی woff2 را می‌خوانند؛ woff فقط پشتیبان مرورگرهای قدیمی است. `eot` لازم نیست.
- **در کد:** متغیر `--font-fa` در `tokens.css` دیزاین سیستم (v2.4) روی پیدا است. لینک Google Fonts وزیرمتن را از `<head>` بردارید.
